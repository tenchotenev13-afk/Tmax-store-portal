## Дати и часови зони — АКТИВЕН

Никога `.toISOString()` за получаване на дата за сравнение в България (UTC+2/+3)
— бута датата с ден назад. Ползвай локални getter методи, или разбивай
`YYYY-MM-DD` низове по компоненти.

- `bulletin.js:455` има коментар точно за това и го прави правилно.
- **`kasa.js:25`, функцията `yesterday()`, още ползва
  `d.toISOString().slice(0,10)`** — това е активният случай, който трябва да се
  оправи. Останалите ~50 срещания са `new Date().toISOString()` за timestamp
  колони, което е коректно и не се пипа.

## Тихи откази при `sbGet` — АКТИВЕН, структурен

`shared.js:7`:
```js
function sbGet(t,q){ return fetch(...).then(function(r){ return r.json(); }); }
```
Обектът на отговора се изхвърля, значи **никое от 167-те извиквания няма как да
провери `res.ok`**. При 401/404 извикващият получава обект с грешка вместо
масив и обикновено гърми по-нататък с неясно съобщение.

Това не е небрежност на 167 места — поправя се в helper-а. `sbPost` и
`sbPostReturn` вече връщат `{ok:…}` правилно и са модел за това как да изглежда.

## Supabase FK 409 при DELETE — АКТИВЕН шаблон

409 при изтриване = child запис блокира. Поправката е да се изтрият child
записите първо в JS, или safety dialog към потребителя. **Не** се решава с
промяна или премахване на constraint-а.

## UNIQUE при multi-dimensional tracking — АКТИВЕН шаблон

При проследяване по няколко измерения (напр. per-store per-date) → upsert
логика (check-then-patch-or-post). Нов constraint без мисъл създава
невъзможни за записване комбинации.

## Кеш след деплой — АКТИВЕН

GitHub Pages + Service Worker кешират агресивно. При „не виждам промяната"
първата стъпка е hard refresh + Application → Service Workers → Unregister,
**преди** да се дебъгва кодът. Историята показва, че мнозинството от случаите
„не работи" са това, а не бъг.

## Кавички в HTML атрибути — ИСТОРИЧЕСКИ, но лесно се връща

HTML се строи чрез конкатенация на низове. Backslash-escape-нати кавички вътре
в `onclick` атрибут (`getElementById(\"x\")`) дават синтактична грешка в
браузъра. Изглежда наред при четене на кода и се чупи само при истински клик.

Затова тестът на бутон е **симулиран клик**, не инспекция на markup.
Правилният начин за вътрешен апостроф е HTML entity `&#39;`.

## Emoji в JS низове — АКТИВНО ограничение

Surrogate pair грешки в по-стари V8 двигатели (стар Android Chrome). Emoji
не влизат в JS стрингове. В HTML съдържание са допустими.
