# 08.11 — sap-prices-vkp2

- Продажни цени от SAP (VKP2) в `product_catalog` (решения на Тенчо 06.11): `sap-prices-vkp2-schema.sql` — 4 nullable колони (`sale_price` numeric, `sale_price_unit` text, `sale_price_valid_from` date, `sale_price_uploaded_at` timestamptz) + функция `catalog_set_sale_prices(p_rows jsonb, p_uploaded_at timestamptz)` (SECURITY INVOKER, САМО UPDATE на ценовите колони по sap_code, връща updated + непознатите кодове). Миграция **20261108150623** (`sap_prices_vkp2`), приложена 08.11 преди push-а; сверка: 4-те колони nullable без default, функцията INVOKER, EXECUTE за anon и authenticated (ACL с =X/ — и PUBLIC), anon има SELECT/UPDATE на колоните; 0 реда с цена. Ред за Живко — в `zhivko-opashka.md` (4-те колони; функцията — не).
- Защо функция, а не upsert-ът на каталога: POST merge-duplicates вмъква ред за непознат материал (забранено), а `product_name` е NOT NULL и INSERT … ON CONFLICT го проверява преди конфликта — порция само с ценови колони пада цялата.
- admin.js, картата „SAP каталог“: „💶 Цени (VKP2)“ само за admin. Колоните по име (`VKP_COLS`), липсваща → грешка без запис; само VKP0; по материал — валидният днес с най-късно „Валиден от“; цена = Сума / Ценова единица; порции по 2000 през rpc, последователно, с прогрес; паднала порция → червено и брой незаписани. Отчет: прочетени, VKP0, обновени, без валидна цена днес, непознати (до 10 кода), грешки, време. Ред „Цени: обновени дд.мм.гггг чч:мм, N артикула“ (N — от последното качване). Нищо друго не показва цените.
- Тест `tests/sap-prices-vkp2.test.js` (34 проверки, истински .xlsx през SheetJS, клик + change; мутации P1–P6 — всички падат); node --check, smoke, пълният npm test.
- Производителност (генериран файл с обема на примера — 113 271 реда, 107 475 материала, 2 526 VKA0; node): XLSX.read 9,9 сек, sheet_to_json 1,1 сек, vkpParse 0,74 сек → 104 949 цени, 53 порции по ~142 KB. Запис: една порция от 1995 реални кода + 5 непознати в транзакция с rollback — 0,76 сек в базата (updated 1995); след rollback 0 реда с цена, updated_at непроменен → 53 порции ≈ 40 сек в базата + мрежата (~142 KB на порция), около минута.
