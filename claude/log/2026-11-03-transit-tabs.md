# 03.11 — transit-tabs

- „Стока на път“, етап 2 от 4 (решенията — `claude/stoka-na-pat-reshenia-2026-11.md` в Проекта на чата): табове „📦📤 Всички“ / „📥 Получавам“ / „📤 Изпращам“ вместо „Получавам“ / „🔄 Трансфери“. Табът е по ролята на гледната точка в реда (`transitViewpoint()`: обект → себе си, склад → складът, офис → избраният в менюто): „Получавам“ = `store_name`, „Изпращам“ = `supplier`, всички посоки. Офис без обект — празна таблица и „Изберете обект от падащото меню…“. В табовете менюто за офиса е гледната точка, за обекта и склада — другата страна.
- Броячи: „N чакат“ (pending като получател), „N за изпр.“ (transfer pending като изпращач); без гледна точка — без числа. Баджът на реда — „📥 Получавам“ / „📤 Изпращам“ спрямо гледната точка, без нея „🏭 От склад“ / „🏬 От магазин“; Excel „Посока“ — „От склад“ / „От магазин“. `transitApplyOpenFocus` → „Получавам“ + „Чакат мен“. transit.js — функции 56 → 60.
- Импорт: доставчик логистичен склад (`TRANSIT_WAREHOUSE_CODES` 5505 / 5518 / 2505 / 2518) → `incoming` независимо от завода; правилото за реален магазин (→ `transfer`) остава първо. Сверката праща `direction` и за съществуващ ред (от етап 1 — заковано в тест). Data-поправка `transit-direction-fix-data.sql` (3 реда `outgoing` → `incoming` по id, проверка преди, rollback) — чака apply_migration след push-а; схема няма → ред за Живко няма.
- Тестове: нов `tests/transit-tabs-role.test.js` (32 проверки, мутанти M1–M5 падат); обновени `transit-counts-follow-filters`, `transit-store-clarity`, `transit-phone-buttons`, `transit-compact`, `transit-export-labels`, `transit-direction-transfer`.
