- **Проба в хранилището** (отделно „давай“ след push): `instrukcii/_proverka.txt`, без ред в documents — качи → DELETE + POST на същия път → обратно четене → изтрий. Да се отчете: минава ли замяната, колко време старото съдържание се сервира на публичния адрес без `?v` и със `?v`, и че след пробата под `instrukcii/` няма нищо. Ако DELETE + POST не минава — спира се; миграция върху storage.objects само с решение на Тенчо.
- **Първо истинско качване:** PDF-ите в `%USERPROFILE%\Documents\Temax-instrukcii` → `npm run instrukcii` (сухо) → `npm run instrukcii -- --go`.
- **Проверка на живо в портала:** admin вижда 11-те карти в „🔒 Само за офиса“, групирани по модул; картата отваря PDF-а; не-admin не вижда папката. Повторно `--go` без промяна → „нищо за правене“ навсякъде.
