Етап 6б на Разлики — проверка на живо след push-а (бутоните на склада и обекта
по категория; само междускладов, ненасочен ред).

1. Логистичен склад Търговище, „Бланки към мен“:
   - липса (undelivered) без отговор → точно 3 бутона: „📤 Изпратено“,
     „⏳ Ще се изпрати със следващ транспорт“, „📄 Приемете по документи,
     пускам нова заявка“;
   - излишък (excess) без отговор → точно 2: „📝 Пуснете заявка ZSTR тип 4“,
     „📄 Изписано по система“; „📤 Изпратено“ го няма;
   - излишък със заварен „Изпратено“ (3 отворени реда към 18.11) → надпис
     „✓ 📤 Изпратено“ + двата бутона; излишък със заварен „Ще се изпрати“
     (2 отворени) → „✓ ⏳ Ще се изпрати“ + двата;
   - редовете „Ход: ЦО“ (15 към 18.11, излишък + return + no_stock) → 0
     бутона на склада, само „📝 Пуснете заявка ZSTR тип 4“ и отговорът на
     обекта;
   - клик на бутон → модалът със същия надпис в заглавието (НЕ натискай
     „Запази“ на реален ред без нужда — записва отговор).
2. Обект с return по липса (към 18.11 отворен такъв без отговор на обекта
   няма — липса+return са само със sap_done, 7 реда; там се вижда
   „✓ 📄 ИЗПИСАНО В SAP“) и по излишък (1 ред без отговор): „📝 ЗАЯВКАТА Е
   ПУСНАТА“ / „⛔ НЯМА НАЛИЧНОСТ В ЛОГИСТИКА“; ред „Ход: обекта — да пусне
   заявка ZSTR тип 4 …“.
3. admin / Цвети: само надписите по категория, без бутони; Excel от
   „Решени редове“ — колоната „Отговор на склада“ с новите надписи.
4. Push при отговор — заглавието по категория („📝 Разлика: Заявката е
   пусната“ и т.н.) — само при реален отговор, не се предизвиква нарочно.
