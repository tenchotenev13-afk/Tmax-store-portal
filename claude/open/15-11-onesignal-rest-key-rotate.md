- **OneSignal — смяна на REST ключа.** На 15.11.2026 неизползваната константа `OS_API_KEY` (REST ключ `os_v2_app_…`) е махната от `push.js`. Ключът обаче остава в историята на git и до този push се сервираше от GitHub Pages — тоест е изтекъл и трябва да се смени. Известията вървят през едж функцията `portal-push` със секрета `ONESIGNAL_REST_KEY`; дали секретът е СЪЩАТА стойност, от репото не се вижда — затова редът е важен (стар раздел за същото: `claude/open-tasks.md`, „OneSignal REST ключ в push.js“, 11.09.2026; стъпка 5 там вече е направена):
  1. OneSignal → Settings → Keys & IDs → нов REST API ключ.
  2. Supabase → Edge Functions → Secrets → `ONESIGNAL_REST_KEY` = новата стойност.
  3. Проверка: ръчно известие от портала (напр. „🔔 Нотификации“ в Бюлетина) — да пристигне.
  4. Чак след това — отмяна на стария ключ в OneSignal.
