- Проверка на живо след push (ред „Проверено (снабдител / началник склад): имена … подпис …"):
  - Трансфери → реален трансфер → „🖨 Печат" → предварителен преглед: редът е на един ред, над „Предал / Превозвач / Приел", „Проверено" удебелено; брой листове като досега.
  - Товарни листи → реален лист → „🖨 Печат" (склад) и „🖨 Печат" на обект: редът над „Товарил / Приел"; „⬇ PDF" — редът преди „Товарил: … Приел: …", „Проверено" удебелено.
  - По желание: „🖨 Опис" на палет с артикули (на живо такива единици има само 3).
- Решено (Тенчо 12.11): в PDF-а трите реда (Проверено / Товарил / Приел) се пазят заедно — нов лист ПРЕДИ „Проверено", когато не се побират; HTML листите с „Отпечатано …" сам на 2-ри лист са приети. По желание на живо: „⬇ PDF" на дълъг лист, при който подписите падат на нов лист — трите реда заедно.
